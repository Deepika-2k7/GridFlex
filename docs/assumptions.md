# Prototype assumptions

Default demo: 500 households, 250 kW solar, 50 kW wind, 500 kWh battery, 74% starting SOC, 75% response participation, grid available, ₹8/kWh energy tariff and ₹12/kWh evening peak tariff. Demand is a neighbourhood aggregate synthetic profile. The UI exposes scale, generation, battery, participation, scenario and grid availability. Simulation interval is fixed to 15 minutes and duration to 24 hours. Values are configurable prototype assumptions, not measurements.

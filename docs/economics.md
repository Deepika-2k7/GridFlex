# Economics

The demo estimates import cost by multiplying simulated grid import by ₹8/kWh and adding a ₹4/kWh peak premium from 17:00 to 22:00. Daily savings are the nonnegative difference between baseline and GridFlex modeled energy bills. Household benefit divides this estimate by the configured household count in UI examples. Capital expenditure, maintenance, lifecycle replacement, tariff rules and financing are not modeled; payback is therefore not represented as a reliable investment result.
